Spends Plan Tracking

This dashboard consolidates the Spends Plan of the Scaling Team at both the month-to-date and D-2 levels, for the current Growth shows. The purpose is to gauge overspending/shortfall patterns to take corrective actions for maintaining planned Daily & Monthly Spends.

Script-level Spends

This view breaks spend down the current Growth shows' spends at a Script X Platform X Media Source level. The data is populated from 1st September till date, on a D-2 level.

Show Wise Recoveries

This dashboard provides a read of Paybacks and other early metrics across Growth shows of 3 genres - Fantasy, Romantasy & Romance/Drama. Filters let you narrow the view by refresh date, show, sub-team, and language. Weekly blocks are intended to show short-term performance trends over time.

Retention View

This dashboard shows Retention performance (via QS) and normalized retention metrics at the ad set level, segmented by show, platform, and media source. Use the filters to analyze cohort maturity and track week-by-week retention trends.

  • Ad Set ID selection is mandatory.
  • Campaign ID selection is optional.
